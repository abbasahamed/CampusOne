## Phase 03 design guidance

Local skill sources were `.agents/skills/frontend-design` for composition, `.agents/skills/minimalist-skill` for open hierarchy and restraint, `.agents/skills/apple-design` for typography and immediate feedback, and `.agents/skills/emil-design-eng` for interaction timing and reduced motion. Apple Fitness, Linear, Structured and Revolut supplied design principles named in the project brief. The application uses the existing runtime packages and the original CampusOne mark.
